StatsPro

Turn raw CSV data into professional statistical reports — hypothesis tests, visualizations, AI insights, AutoML and PDF export. No code required.

Launch the app → View on GitHub

The app runs on Streamlit Community Cloud. If it was idle it may take up to a minute to wake.

Preprocessing

KNN imputation, IQR outlier handling, duplicate and constant-column removal, quality score.

Statistical tests

Scale-aware normality, correlations with CIs, chi-square with Cramér's V, ANOVA with effect sizes, VIF, regression, FDR correction.

ML Studio

Six models with cross-validation, permutation importance, diagnostics, live and batch prediction, model export.

Reports

AI-generated narrative insights and a downloadable PDF report.

Run it on your own machine

git clone https://github.com/Junaid-Ahmed-Rupok/statistical-analysis-app.git
cd statistical-analysis-app
./run.sh        # macOS / Linux  (Windows: run.bat)
# or with Docker:
docker build -t statspro . && docker run -p 8501:8501 statspro
